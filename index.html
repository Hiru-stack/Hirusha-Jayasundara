Overview: Currently expanding the SmartLoan AI project into formal academic research, evaluating machine learning prediction models that analyze loan approval probabilities based on user financial details.

Key Focus Areas:

  • 01
    Data Preprocessing: Data collection & preprocessing methodologies. Custom feature engineering for highly skewed financial profiles.
  • 02
    Exploratory Analysis (EDA): Exploratory Data Analysis (EDA) on financial datasets to identify core correlation parameters.
  • 03
    Model Benchmarking: Building and benchmarking loan prediction models (Random Forests, XGBoost, etc.).
  • 04
    Prediction Accuracy: Tuning hyperparameters to maximize AI-powered loan approval prediction accuracy.

Strategic Objective

To strengthen the understanding of how intelligent systems support financial decision-making, with the ultimate objective of publishing the findings at the upcoming ICTer Conference.
