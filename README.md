# Hirusha Jayasundara - Personal Portfolio

Welcome to the repository for my personal portfolio website! This project serves as a digital resume and a showcase of my skills, projects, and achievements as a Data Scientist and AI Engineer.

## 🌟 Overview

A highly modern, premium portfolio website featuring a dark-themed aesthetic, smooth micro-animations, and glassmorphism UI elements. Designed to highlight my background in **Data Science, Artificial Intelligence, and Data Engineering**, and to connect with recruiters for internship opportunities.

## ✨ Features
- **Modern UI/UX**: Custom-designed dark theme with glowing ambient background blobs and frosted glass containers (`backdrop-filter`).
- **Fully Responsive**: Optimized seamlessly for both desktop and mobile viewing.
- **Dynamic Projects**: A dedicated section to display my end-to-end data pipelines, predictive models, and interactive dashboards.
- **Working Contact Form**: Integrated with Formsubmit.co to securely forward messages directly to my email without needing a backend server.

## 🛠️ Built With
- **HTML5**: Semantic structure and organization.
- **CSS3 (Vanilla)**: All styling, grid/flexbox layouts, responsive media queries, and animations. No heavy CSS frameworks—just pure, tailored CSS.
- **JavaScript**: Smooth scrolling and dynamic element handling.
- **FontAwesome**: Scalable vector icons for social media and UI elements.

## 🚀 Getting Started (Local Development)

Because this is a static website, no complex build tools or dependencies are required. 

To run it locally:
1. Clone the repository: `git clone https://github.com/Hiru-stack/Hirusha-Jayasundara.git`
2. Navigate to the project directory.
3. Start a local server. For example, using Python:
   ```bash
   python -m http.server 8080
   ```
4. Open `http://localhost:8080` in your web browser.
